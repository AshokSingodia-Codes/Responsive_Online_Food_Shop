# Responsive Online Food Shop

🌐 **Live Demo:** [Responsive Online Food Shop on Vercel](https://responsive-online-food-shop.vercel.app)

A clean, responsive food ordering website built using **HTML5 and CSS3**. Designed for smooth user navigation across desktops, tablets, and mobile devices.

## 🚀 Features
- **Responsive Layout**: Fluid design adaptable to all screen sizes.
- **Sticky Navigation Bar**: Easy access to sections.
- **Services Showcase**: Clean layout for ordering, catering, and bulk services.
- **Contact Form**: Functional UI form for user inquiries.

## 🛠️ Built With
- **HTML5**
- **CSS3** (Flexbox & Media Queries)
- **Google Fonts**

## 🌐 Deployment
This static website can be instantly deployed on **Vercel**, **GitHub Pages**, or **Netlify**.
